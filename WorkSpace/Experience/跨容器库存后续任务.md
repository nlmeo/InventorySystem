# 跨容器库存后续任务

## 当前最高优先级

1. 抽取客户端跨容器交换规划函数。
2. 让高亮和拖放提交复用同一份规划结果。
3. 整理服务器批量计划校验。
4. 移除跨容器旧单目标交换回退路径。

## 次优先级

- 专用服务器下复制子对象换宿主重复验证。
- 断线重连、重开容器和重开背包验证。
- 统一普通拖拽、快速转移、装备、丢弃事务入口。
- 清理装备事件重复触发兼容逻辑。
- 增加自动化回归测试。

## 关键约束

- Session 是玩家背包和容器 UI 的唯一纽带。
- 所有容器客户端请求通过 PlayerController 转发。
- 跨容器整件物品复用原复制子对象，不创建副本。
- 客户端负责交换规划和高亮。
- 服务器只校验客户端提交的交换计划和权威状态。
- 服务器拒绝时整笔事务回滚。
- 不恢复 `UINV_SpatialInventory::RebindInventoryForSession()`。

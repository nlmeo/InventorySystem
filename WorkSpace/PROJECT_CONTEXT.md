## 已掌握的实现约束

- 位置必须同时看 ContainerId / SlotId 与 GridIndex，索引只在所属容器内有意义。
- GetItemDimension() 是实际占地，GetBaseDimension() 是原始绘制尺寸。
- Payload 朝向是拖拽临时状态；清旧占区先于写新朝向。
- PlaceHoverItemAtDropIndex 统一两个 Drop 入口，再按朝向是否变化分派。
- 同朝向重排使用整数位移/反射；分离区域旋转重排使用互逆的整数 90° 映射。
- 批次先完成校验，再全部清旧占用，最后统一落位；主物品引用须在 Payload 清空前保存。
- 当前 bServerAuthoritativeUI 默认开启，但仍存在本地预测写入；不能据此声称已实现完整事务回滚。
- 最新 B 组修复在松手时重算落点，直接落位前再次检查占用；权威快照回复携带容器、索引、数量和朝向，客户端应用后再重铺。
